The uploaded zip file contains generated images of cities in rainy/sunny weather and realistic/artistic style and some specifically marked images.
Your task is to train or come up with _three_ image classifiers:
1. A model that predicts whether it is rainy/sunny.
2. A model that predicts realistic/artistic.
3. A model that predicts the marked images.

You need to use Python.
You can use any deep learning library you like (Pytorch is preferred).
We want to see a deep learning-based solution, i.e., no SVM etc. for tasks 1 and 2.
For task 3, you can use a more basic solution as well.

You can use Google Colab to have access to a GPU.
